# Course - RESTful APIs with Spring Boot, Docker and Cloud

## About

Repository dedicated to practical exercises and projects developed during the course **RESTful APIs from Zero to Cloud with Spring Boot and Docker**.

## Technologies

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Docker
- REST APIs
- Swagger / OpenAPI
- Git and GitHub

## Topics Covered

- RESTful API development
- HTTP methods and status codes
- Database integration
- CRUD operations
- Exception handling and validation
- API documentation
- Automated testing
- Authentication and security
- Docker containerization
- Cloud deployment concepts

## Objective

Develop practical skills in backend development, learning to build, test, document, containerize, and deploy RESTful APIs using modern technologies and best practices.
